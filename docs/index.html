01 / 功能

不只是拦截广告。更是重拾注意力。

AdShield 覆盖浏览器里绝大多数「噪音」——横幅、追踪器、埋点、弹窗、跳转参数，以及悄悄运行的挖矿脚本。

01
广告拦截
横幅、弹窗、视频贴片、信息流，覆盖主流广告网络。
02
追踪防护
阻断第三方跨站追踪器，浏览行为不外泄。
03
URL 清理
自动去除 utm_*、gclid、fbclid 等追踪参数。
04
元素隐藏
隐藏广告容器，让版面重新干净。支持自定义选择器。
05
反拦截检测
规避站点检测脚本，不再被「请关闭广告拦截」打扰。
06
恶意防护
拦截挖矿脚本与已知的恶意、欺诈分发域名。
07
规则订阅
订阅 EasyList China / AdGuard / EasyPrivacy 等主流规则源。
08
云同步
可选账号：跨设备同步配置、白名单、自定义规则。
09
账号安全
密码强度策略、登录失败锁定、多设备管理。

03 / 安装

三十秒，开始使用。

从 Edge 商店推荐

  1. 打开 Edge 商店页面
  2. 点击「获取」按钮
  3. 浏览器会自动安装
前往商店

开发者模式加载

  1. 下载并解压最新 zip 包
  2. 打开 chrome://extensions/
  3. 开启右上角「开发者模式」
  4. 点击「加载已解压的扩展程序」
  5. 选择解压后的目录

04 / 隐私

你的数据，留在你的浏览器里。

  • 默认所有数据存储于本地，不上传任何信息
  • 不收集浏览记录、搜索历史、页面内容
  • 不接入任何广告、分析或遥测服务
  • 不使用远程代码，所有 JS 随扩展打包
  • 可选账号仅收集邮箱与加密密码，用于跨设备同步
  • 开源可审计，源码完全公开
