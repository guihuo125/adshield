🏪 从 Edge 商店安装 推荐

  1. 打开 Edge 商店页面
  2. 点「获取」按钮

📦 开发者模式加载

  1. 下载并解压 zip 包
  2. 打开 chrome://extensions/
  3. 开启右上角「开发者模式」
  4. 点「加载已解压的扩展程序」
  5. 选择解压后的目录
