# AdShield 广告拦截器

> 轻量、隐私优先的广告与追踪拦截扩展，基于 Manifest V3 开发。

[![Version](https://img.shields.io/badge/version-2.9.8-blue)]()
[![Manifest](https://img.shields.io/badge/Manifest-V3-green)]()
[![License](https://img.shields.io/badge/license-MIT-orange)]()

## ✨ 功能特性

| 特性 | 说明 |
|------|------|
| 🚫 **广告拦截** | 拦截横幅、弹窗、视频贴片、信息流广告 |
| 🛡 **追踪防护** | 阻止网站和第三方追踪器收集您的浏览行为 |
| 🧹 **URL 清理** | 自动去除 utm_*、gclid、fbclid 等追踪参数 |
| 👁 **元素隐藏** | 隐藏页面中的广告容器（含国内门户、百度联盟、广点通） |
| 🕵 **反拦截检测** | 规避网站的检测脚本，不再被"请关闭广告拦截"困扰 |
| 🤖 **浏览助手** | 检测到反拦截脚本时自动暂停该站点，避免页面异常 |
| 🦠 **恶意防护** | 拦截浏览器挖矿脚本与已知恶意/欺诈分发域名 |
| 📡 **规则订阅** | 支持在线订阅 EasyList China / AdGuard 等规则源，自动更新 |
| ⚙️ **自定义规则** | 支持 AdGuard / uBlock 风格自定义规则 |
| 📊 **拦截统计** | 分类趋势图、Top 域名榜（数据仅本地存储） |
| 👤 **账号系统** | 支持注册/登录、修改密码、多设备管理（可选，基于 Supabase） |
| ☁️ **云同步** | 跨设备同步设置、白名单、自定义规则（可选，需登录） |
| 💾 **数据备份** | 导出/导入 JSON 配置文件，一键迁移 |

## 📦 安装

1. 下载本仓库的 Release zip 包并解压
2. 打开 `chrome://extensions/`（Edge 用 `edge://extensions/`）
3. 开启右上角 **开发者模式**
4. 点 **加载已解压的扩展程序**，选择解压后的目录
5. 加载提示选 **保留**

## 🎯 使用说明

### 弹窗（Popup）

- 点击扩展图标 → 查看本站 / 累计拦截数
- 圆环图 → 按分类（广告 / 追踪 / 干扰 / URL / 恶意）展示占比
- 暂停卡片 → 选择「1 小时 / 1 天 / 始终」快速暂停本站
- 菜单 → 全局开关 / 防护类型 / 工具（拾取器、日志、清数据）

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Alt+A` | 全局暂停 / 恢复 |
| `Alt+S` | 当前网站暂停 / 恢复 |

### 右键菜单

在网页空白处右键 → 可直接：暂停本站 / 恢复 / 隐藏元素 / 打开设置

### 规则订阅（v2.4+ 新增）

在「设置 → 规则管理」中：

1. **推荐订阅**：一键添加 EasyList China / AdGuard 中文 / EasyPrivacy 等规则源
2. **自定义订阅**：粘贴任意规则源 URL（支持 JSON 和 uBlock / AdGuard 文本格式）
3. **自动更新**：可设置 6 / 12 / 24 / 48 小时 / 7 天更新一次
4. **先验证再保存**：拉取失败不会添加，避免脏数据

### 自定义规则

在「设置 → 规则管理」里添加，支持以下语法：

```
! 这是注释
||ads.example.com^      域名拦截（含子域）
/banner/                路径片段拦截
@@||mysite.com^         例外规则（放行）
example.com##.ad        元素隐藏（仅该站）
##.global-ad            元素隐藏（全站）
```

### 元素拾取器

1. popup 菜单 → **隐藏内容块**
2. 鼠标悬停在页面元素上 → 点击
3. 选择「仅本站」或「所有站点」
4. 自动生成 CSS 选择器规则

### 账号与云同步（可选）

在「设置 → 账号」中：

1. **注册/登录**：使用邮箱 + 密码（≥6 位）
2. **云同步**：勾选需要同步的项目（基础设置 / 白名单 / 自定义规则 / 订阅）
3. **多设备**：登录后自动上报设备信息（操作系统 + 浏览器）
4. **数据备份**：导出/导入 JSON 文件，可手动备份或迁移
5. **修改密码**：需原密码验证
6. **删除账号**：二次确认，永久删除云端数据

> ⚠️ 首次注册后，请记得在「设置 → 账号 → 云同步」中点击「上传到云端」，之后修改配置会**自动上传**（5 秒防抖）。

## 🔒 隐私承诺

- ✅ **默认所有数据存储于本地浏览器**，不上传任何信息
- ✅ **不收集任何用户数据**（无埋点、无分析、无遥测）
- ✅ **不发起任何网络请求**（除用户主动添加的规则订阅外）
- ✅ **不使用远程代码**（所有 JS 随扩展打包）
- ⚠️ **可选账号功能**：仅在用户**主动注册/登录**后，才会将以下数据同步到 Supabase 云端：
  - 邮箱（仅用于登录，不用于营销）
  - 加密后的密码（Supabase 托管）
  - 用户主动同步的配置（设置/白名单/自定义规则）
  - 设备信息（用于多设备列表展示）
- ✅ 完整隐私政策见 [PRIVACY.md](./PRIVACY.md)

## 🛠 技术栈

- **Manifest V3**
- **declarativeNetRequest** — 网络层拦截（静态规则 + 动态规则）
- **Content Scripts** — 元素隐藏 / 反拦截检测 / 元素拾取器
- **Service Worker** — 后台逻辑、订阅管理、统计
- **原生 JavaScript**，无第三方框架

## ❓ 常见问题

**Q1: 为什么有些广告没被拦？**

A: 规则库持续更新中。你可以通过「设置 → 规则管理」订阅 EasyList China 等规则源，或添加自定义规则，也可以访问 GitHub Issues 反馈。

**Q2: 会不会影响网页加载速度？**

A: 网络层拦截在浏览器原生 API（declarativeNetRequest）完成，几乎无性能开销。元素隐藏通过轻量 Content Script 完成，有防抖优化。整体资源占用极低。

**Q3: 统计数字一直是 0？**

A: 统计功能依赖浏览器的 `declarativeNetRequestFeedback` API。在开发者模式加载扩展时实时生效；从商店安装的版本受浏览器限制，统计可能不更新。

**Q4: 为什么拦截数很高（如某网站 60 条）？**

A: 统计为**累计值**（多次访问总和），且会统计：
- 广告请求
- 追踪/埋点上报
- URL 参数清理
- 干扰内容

国内大型站点（如 B站首页）单次访问就有 30~60 个埋点上报，属正常。

**Q5: 浏览助手会误暂停网站吗？**

A: 已对 40+ 主流站点（B站/知乎/微博/淘宝等）加入白名单，跳过检测。仅在明确检测到反拦截脚本时触发。

**Q6: 如何完全卸载？**

A: 在扩展管理页点「移除」即可。所有本地数据会一并删除。**若已登录账号**，请先在「设置 → 账号」中删除账号，以清除云端数据。

**Q7: 账号是必须的吗？**

A: **不必须**。不登录也能正常使用所有拦截功能。登录后可以跨设备同步配置、查看设备列表、备份数据。

**Q8: 账号数据安全吗？**

A: 密码由 Supabase 托管（行业标准），我们**无法读取您的密码**。同步的配置数据仅您本人可访问（行级安全策略），不会共享给第三方。
