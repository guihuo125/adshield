# AdShield 广告拦截器

一个跑在 Manifest V3 上的广告与追踪拦截扩展，Chrome 和 Edge 都能用。

[![Version](https://img.shields.io/badge/version-2.9.93-blue)]()
[![Manifest](https://img.shields.io/badge/Manifest-V3-green)]()
[![License](https://img.shields.io/badge/license-MIT-orange)]()

## 它做什么

拦截分两层。网络层用 declarativeNetRequest 挡住广告、追踪器、干扰内容和恶意域名，
覆盖 800 多个域名，包括百度联盟、广点通这些国内常见的；页面层再负责把剩下的广告容器隐藏掉。
网址里带的 utm_*、gclid、fbclid 这类追踪参数会被清掉。

不少站点会检测你有没有装拦截器。能骗过去的就骗过去（伪装成没装），代价太大的就自动暂停
这一站一小时，免得页面直接坏掉。

规则可以订阅，也可以自己写。订阅默认带 EasyList China、AdGuard 中文、Fanboy Annoyance、
EasyPrivacy 四个源，打开规则页会检查更新，也能设成每 6、12、24、48 小时或 7 天自动拉一次。
自己写支持 AdGuard / uBlock 的语法，不想写代码可以用元素拾取器直接点选页面元素。

统计按分类记，有趋势图和 Top 域名榜，数据只存在本地。日志能导出 JSON 或 CSV。

账号是可选的，不登录所有拦截功能照常。登录之后，配置、白名单、自定义规则和订阅可以跨设备
同步，也能导出 JSON 手动备份。

## 安装

Edge 商店有上架，但版本停在 v2.0.0，比 GitHub 落后不少：
[Edge 商店](https://microsoftedge.microsoft.com/addons/detail/ogjodahjklhodkmnjhopkopflngicokg)

想用最新版（v2.9.93），从 Release 下载 zip 走开发者模式：

1. 下载 Release 里的 `adblocker-v2.9.93.zip` 并解压
2. 打开 `chrome://extensions/`，Edge 用 `edge://extensions/`
3. 右上角开启开发者模式
4. 点「加载已解压的扩展程序」，选中解压出来的文件夹
5. 浏览器提示时选「保留」

Release 里也有 crx，拖进扩展页面同样能装。

## 使用

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Alt+A` | 全局暂停 / 恢复 |
| `Alt+S` | 当前网站暂停 / 恢复 |

网页空白处右键也能直接暂停本站、恢复、隐藏元素或打开设置。

### 弹窗

点扩展图标，能看到本站和累计的拦截数。圆环按分类拆开（广告、追踪、干扰、URL、恶意），
下面有暂停卡片，可以选暂停 1 小时、1 天或始终。菜单里是全局开关、防护类型，以及一些工具。

### 规则订阅

在「设置 → 规则管理」里：

- 推荐订阅，一键加上 EasyList China、AdGuard 中文、EasyPrivacy 这类源
- 自定义订阅，粘贴任意规则源网址，JSON 和 uBlock / AdGuard 文本格式都认
- 自动更新间隔可选 6、12、24、48 小时或 7 天
- 拉取失败不会保存，避免把脏数据加进来

### 自定义规则

同样在「设置 → 规则管理」，支持的语法：

```
! 注释
||ads.example.com^      按域名拦截，含子域
/banner/                按路径片段拦截
@@||mysite.com^         例外，放行
example.com##.ad        隐藏元素，只在这一个站生效
##.global-ad            隐藏元素，所有站点生效
```

### 元素拾取器

弹窗菜单里点「隐藏内容块」，鼠标移到页面元素上点一下，选「仅本站」或「所有站点」，
扩展会自动生成对应的 CSS 选择器规则。加过的隐藏规则在规则管理页能查看、删除或导出。

### 界面与其他

深色模式有亮色、跟随系统、暗色三档。拦截时想收系统通知可以打开，默认关闭，开了之后
60 秒内最多弹一次，且至少拦够 5 条才提醒，不会刷屏。

### 账号与同步

设置里的账号页可以邮箱注册登录，密码至少 8 位、要含大写字母，常见弱密码会被拒。
登录后勾选要同步的内容（基础设置、白名单、自定义规则、订阅这几类），首次记得手动点一次
「上传到云端」，之后改配置会在 5 秒后自动上传。同一个页面能看登录过的设备，改密码要验证原密码，
删账号会连带清掉云端数据。密码连续输错 5 次会锁 15 分钟，30 天没操作自动登出。

## 隐私

默认所有数据都留在本地浏览器里。没有埋点，没有分析，没有遥测，也没有远程加载的代码，
所有 JS 都随扩展打包。

会联网的情况只有三种：首装自带的 4 个订阅源定时更新（可以关掉或调间隔）、你自己添加的订阅源、
以及登录后的 Supabase 同步。

账号是可选的。注册登录之后才会同步这些到 Supabase：邮箱（只用于登录）、密码（Supabase 托管，
我读不到）、你勾选同步的配置、以及设备信息（用于设备列表展示）。完整条款见 [PRIVACY.md](./PRIVACY.md)。

## 技术栈

Manifest V3、declarativeNetRequest（静态规则加动态规则）、Content Scripts、Service Worker。
原生 JavaScript，没有框架，没有构建步骤，目录解开就能加载。

    ├── shared/

## 常见问题

**为什么有些广告没被拦？**

规则库一直在更新，但覆盖率不会是 100%。可以在「设置 → 规则管理」订阅 EasyList China 这类源，
或者自己加规则。有漏拦的欢迎提 Issue。

**会不会拖慢网页加载？**

网络层拦截走的是浏览器原生 API，几乎不占时间。元素隐藏的 Content Script 做了防抖，
只有页面上确实有匹配元素时才动手。

**统计数字一直是 0？**

统计依赖 `declarativeNetRequestFeedback`，这个 API 只在开发者模式加载扩展时才有值。
从 crx 或商店装的版本拿不到数据，界面上会显示降级提示。

**为什么拦截数这么高，某个网站一次就 60 条？**

统计是累计值，多次访问会加在一起。计入总数的有广告请求、追踪和埋点上报、干扰内容、恶意域名四类。
URL 参数清理属于重定向不算拦截，不计入总数，但会在分类占比里单独显示。
国内大站首页单次就有 30 到 60 个埋点上报，属于正常。

**浏览助手会不会把好好的网站暂停掉？**

B站、知乎、微博、淘宝等 40 多个主流站点已经加进白名单跳过检测，只有在确实读到反拦截脚本时才会触发。

**怎么彻底卸载？**

扩展管理页点「移除」，本地数据会一起删掉。如果登录过账号，先在「设置 → 账号」里删账号，把云端数据也清掉。

**必须登录吗？**

不需要。不登录也能用全部拦截功能，登录只是为了跨设备同步和备份。

**账号数据安全吗？**

密码由 Supabase 托管，我读不到。同步的配置只有你本人能读写，匿名请求拿到的是空结果。
这条边界靠数据库的行级安全策略保证，策略原文在 [`docs/supabase-rls.sql`](docs/supabase-rls.sql)。
