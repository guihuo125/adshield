常规设置

管理 AdShield 的各项防护功能。所有数据均存储于本地浏览器，不上传任何信息。

全局保护
一键开启或关闭所有广告与追踪拦截。
反拦截检测
规避网站的检测脚本，不再被"请关闭广告拦截"困扰。
浏览助手
检测到网站使用广告拦截检测脚本时，自动暂停该站点保护，避免页面异常。
显示拦截数量
在工具栏图标上显示当前页面已拦截的请求数。
分类开关
独立控制 5 类规则的启用状态。关闭后对应的拦截规则立即失效。
广告拦截
横幅、弹窗、视频贴片、信息流
追踪防护
第三方跨站追踪器
干扰过滤
推送请求、弹窗挂件、反拦截脚本
URL 清理
自动去除 utm 等追踪参数
恶意防护
挖矿脚本、恶意分发域名
暂停 AdShield
暂停全局保护，1 天后自动恢复

添加在线订阅、编写自定义拦截规则。

规则订阅
从在线来源自动更新规则（支持 JSON 和 uBlock / AdGuard 文本格式）。

每行一条。保存后会立即通过 declarativeNetRequest 动态规则生效，无需重新加载扩展。

    导入 / 导出
    导出会把所有设置、自定义规则、白名单打包成 JSON 文件，方便备份或迁移到其他设备。

    网站
